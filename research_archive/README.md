# Drone Libre Research Archive

This folder is the structured mirror library for outside projects, concepts, and reference designs that may help Drone Libre.

## Directory Map

- [Airframes](airframes/) — drone frames, VTOL structures, optimized arms, and printable frames.
- [Radar](radar/) — radar, RF sensing, ranging, and ground-station detection projects.
- [Robots](robots/) — quadrupeds, walking drones, leg mechanisms, and robotic locomotion.
- [Sensors](sensors/) — cameras, optical flow, LiDAR, ToF, thermal, GPS, IMU, and sensor-fusion references.
- [Companion computers](companion_computers/) — ESP32, Raspberry Pi, Linux, AI companion, RID, telemetry, and coordination projects.
- [Ground station](ground_station/) — controllers, displays, antennas, SDR, command stations, and field cases.
- [Software](software/) — firmware, open-source flight control, autonomy, mapping, scanning, and tooling.
- [Materials testing](materials_testing/) — print settings, filament testing, crash testing, and strength notes.
- [Source notes](source_notes/) — raw source notes before they are cleaned up into a project mirror.

## Mirror Entry Format

Start new entries from [MIRROR_TEMPLATE.md](MIRROR_TEMPLATE.md). Each mirrored project should include source attribution, summary, relevance to Drone Libre, files mirrored or still needed, license status, build/test notes, and next steps.

Use these status labels consistently:

- **Source note** — an unprocessed lead or raw capture.
- **Research reference** — summarized, but source files or licensing are incomplete.
- **Mirror** — source files and documentation are stored with attribution and license status.
- **Tested reference** — a mirror with documented build or test results.

## Archive Rule

Do not just hoard links. Capture what is useful, note what is unverified, and turn good ideas into testable Drone Libre tasks.
