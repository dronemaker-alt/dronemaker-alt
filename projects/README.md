## Entry Standard

Each project should identify:

- Current status and owner
- Hardware and firmware baseline
- Design rationale and known assumptions
- Measurements and validation evidence
- Open problems
- The next concrete test

System-wide requirements and subsystem boundaries belong in [`ARCHITECTURE/`](../ARCHITECTURE/). Dated bench observations belong in [`LAB-NOTES/`](../LAB-NOTES/). Outside projects used only as references belong in [`research_archive/`](../research_archive/).
